# Smart City Traffic Capstone Project

Welcome to the Smart City Traffic Capstone repository. This project focuses on analyzing urban traffic data, building robust data pipelines using Python, and applying machine learning models to optimize city traffic flow.

## Repository Structure

* **part1_data_analytics/**: Exploratory data analysis, data cleaning, and statistical insights.
* **part2_python/**: Modular data pipelines, feature engineering modules, and visual reporting.
* **part3_machine_learning/**: Predictive model training, evaluation scripts, and deployment logic.

*Developed as part of the NUS AI, ML, and Data Science Programme (2026).*
